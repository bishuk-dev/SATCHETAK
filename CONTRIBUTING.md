# Contributing

Contributions should advance the current SATCHETAK Land Intelligence MVP.

Before a change:

1. read `docs/PROJECT_SCOPE.md` and `docs/DEVELOPMENT_PLAN.md`;
2. keep Agriculture + Urban/Land scope;
3. add tests for deterministic/geospatial behavior;
4. document provider/model contracts;
5. avoid unsupported claims and premature infrastructure.

Flood/disaster features are outside the current hackathon branch unless scope is explicitly changed.
